About this HTML file

This is a self-contained launcher for the official GeoLibre web application, prepared from the v2.3.0 release reference.

GeoLibre itself is a large React/TypeScript application that uses separate JavaScript modules, Web Workers, WebAssembly binaries, JupyterLite files, map resources, and optional remote services. Those components cannot be reliably collapsed into a conventional single offline HTML document without changing or disabling substantial functionality.

The embedded application is served by https://web.geolibre.app/. Because that deployment can be updated by its maintainers, this launcher targets the v2.3.0 release but cannot permanently pin the hosted application to that version.

GeoLibre is maintained by opengeos and is distributed under the MIT License. View the v2.3.0 release page.
