WiFi Radar Source

True RuView WiFi radar requires raw Channel State Information from compatible hardware such as an ESP32-S3/C6 or a supported research NIC. This phone acts as the display and connects to the sensing server over WiFi. A browser cannot read raw CSI from the phone WiFi chipset.

About

Single-file mobile companion for the open-source RuView project. Includes independently requested phone sensors, permission diagnostics, offline demo mode, and external WiFi-CSI server support for the documented RuView sensing-frame fields, /api/v1/stream/pose, and /ws/sensing. Sensor analysis occurs locally in the browser. Data is not transmitted unless you connect to a server URL.
